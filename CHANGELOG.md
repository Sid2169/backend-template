# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Contribution workflow: short-lived feature branches, Conventional
  Commits, pull request and issue templates, and a self-review
  checklist (#1).
- Fail-fast environment variable validation via `src/config/env.ts`.
- Strict TypeScript configuration, ESLint (flat config, type-aware),
  and Prettier for a Node.js backend.
- VS Code breakpoint debugging configuration for the running Node
  process.
- Git repository with `.gitignore` established before the first
  dependency install.
